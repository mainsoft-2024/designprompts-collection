# 디자인 프롬프트 컬렉션 (designprompts-collection)

이 저장소는 [designprompts.dev](https://www.designprompts.dev/)에서 수집한 **31가지 AI UI 디자인 스타일 프롬프트**를 정리한 컬렉션입니다.
각 프롬프트는 색상 토큰, 타이포그래피, 컴포넌트 규칙, 레이아웃 전략까지 포함해 AI에게 스타일 일관성을 전달하도록 구성되어 있습니다.
아래 표에서 테마별 분위기와 시각적 특징, 추천 활용 맥락을 빠르게 확인할 수 있습니다.

```bash
node scrape-prompts.js
```
